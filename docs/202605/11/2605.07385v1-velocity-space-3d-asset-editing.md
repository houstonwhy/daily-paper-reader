## 摘要
局部编辑 3D 资产，即在修改目标区域的同时保留其余部分，是原生 3D 编辑的一项基本需求。现有方法通过生成器外部的机制来强制实现局部性，例如手动 3D 掩码、事后体素合并或 2D 多视图提升。它们都没有在破坏真正发生的地方进行干预：即 ODE 采样器内部。为了让整流流（rectified-flow）生成器实现忠实的局部编辑，其速度场应在目标编辑区域较强，而在保留内容上趋于消失。然而，单一速度场很难同时满足这两个要求，从而导致三个问题：(i) 身份泄露，使得编辑信号在保留区域保持非零；(ii) 缺乏专门的编辑放大通道，因此加强编辑不可避免地会扰动身份；(iii) 在几何和材质阶段存在身份拖拽，此时全局条件会将每个 token 都拉向目标。我们提出了 VS3D（速度空间 3D 资产编辑），这是一个无需反演、无需训练且无需掩码的框架，通过在采样器内部进行针对性干预来解决上述每个问题。VS3D 集成了三个互补的模块，每个模块对应编辑流水线的一个特定阶段。重建锚定源注入（RASI）通过将无条件嵌入转换为通过源重建校准的、逐步骤且特定于资产的锚点，从而吸收身份泄露。部分均值引导（PMG）通过对比速度差的高质量和低质量子样本估计来放大编辑信号，且仅在存在一致编辑的地方激活。双重一致性残差注入（TAR）让采样器在几何和材质阶段逐 token 决定保留哪些内容。

## Abstract
Editing a 3D asset locally, modifying a target region while preserving the rest, is a fundamental requirement of native 3D editing. Existing methods enforce locality through mechanisms external to the generator, such as manual 3D masks, post-hoc voxel merging, or 2D multi-view lifting. None of them intervene where the corruption actually originates: inside the ODE sampler. For a rectified-flow generator to achieve faithful local editing, its velocity field should be strong over the target editing region while vanishing on preserved content. Yet a single velocity field can hardly satisfy both requirements simultaneously, leading to three problems: (i) identity leakage that keeps the edit signal non-zero on preserved regions; (ii) no dedicated edit-amplification channel, so strengthening the edit inevitably perturbs identity; and (iii) an identity drag at the geometry and material stages, where a global condition pulls every token toward the target. We propose VS3D (Velocity-Space 3D Asset editing}), an inversion-free, training-free, and mask-free framework that addresses each problem with a targeted intervention inside the sampler. VS3D integrates three complementary modules, each corresponding to a specific stage of the editing pipeline. Reconstruction-Anchored Source Injection (RASI) absorbs identity leakage by turning the unconditional embedding into a per-step, asset-specific anchor calibrated through source reconstruction. Partial-Mean Guidance (PMG) amplifies the edit signal by contrasting high- and low-quality subsample estimates of the velocity difference, active only where a consistent edit exists. Twin-Agreement Residual injection (TAR) lets the sampler decide token by token what to preserve at the geometry and material stages.

*   **核心挑战**：在 3D 资产的局部编辑中，如何在修改目标区域的同时，严格保持非编辑区域的原始身份（Identity）。
*   **现有局限**：目前的 3D 编辑器通常依赖外部机制（如手动 3D 掩码、事后体素合并或 2D 多视图提升），这些方法要么操作繁琐，要么容易在边界产生伪影。
*   **研究发现**：作者指出，身份破坏的根源在于 **ODE（常微分方程）采样器内部的速度场（Velocity Field）**。在基于整流流（Rectified-flow）的生成器中，速度场在非编辑区域无法完全消失，导致了“身份泄露”、“缺乏专用编辑放大通道”以及“全局条件拖拽”三个核心问题。
*   **目标**：提出一种**免反演（Inversion-free）、免训练（Training-free）且无需掩码（Mask-free）**的框架，直接在速度空间进行干预。

### 2. 方法论：核心思想与关键技术
VS3D 通过在 ODE 采样器的三个阶段引入针对性模块来解决上述问题：

*   **重建锚定源注入 (RASI)**：
    *   **目的**：消除非编辑区域的身份泄露。
    *   **细节**：将原本通用的“无条件嵌入（null embedding）”转换为逐步骤、特定于资产的锚点。通过一个源重建探测器（Source-reconstruction probe），优化该嵌入以吸收 CFG 不对称和全局注意力带来的残差，使速度差在非编辑区域趋于零。
*   **部分均值引导 (PMG)**：
    *   **目的**：在不扰动身份的前提下增强编辑信号。
    *   **细节**：利用蒙特卡洛估计的结构，对比高、低质量的子样本速度差估计。通过外推法放大一致的编辑信号。该机制是自门控的：仅在 RASI 未抑制速度的编辑区域激活。
*   **双重一致性残差注入 (TAR)**：
    *   **目的**：解决几何和材质阶段的全局身份拖拽。
    *   **细节**：在稀疏 DiT 阶段，运行一个使用源图像条件的“孪生前向过程”。通过对比目标分支和孪生分支的 Token 差异，自动识别哪些 Token 需要保留。对于一致的 Token，将源资产的编码残差注入其中，以恢复精细的纹理和几何细节。

### 5. 实验数量与充分性
*   **实验规模**：论文在多样化的 3D 资产（角色、动物、车辆、日常用品）上进行了大规模定性展示，并提供了详尽的定量对比表。

### 6. 主要结论与发现
*   **性能领先**：VS3D 在身份保持和编辑忠实度的大多数指标上均排名第一，显著优于现有的原生 3D 编辑器和 2D 提升方法。
*   **速度空间干预的有效性**：证明了无需外部掩码，仅通过控制 ODE 采样器内部的速度场，即可实现高精度的局部编辑。
*   **通用性**：该方法作为一种通用的编辑范式，可以适配预训练的 3D 整流流生成器。

### 7. 优点
*   **完全自动化**：无需用户手动绘制 3D 掩码，降低了使用门槛。
*   **高保真度**：通过 RASI 和 TAR 实现了极佳的几何与纹理保留，避免了硬边界伪影。
*   **高效性**：免训练、免反演的设计使其能够实现近乎实时的编辑响应。
*   **灵活性**：能够处理复杂的复合编辑（同时增加和删除）。

### 8. 不足与局限
*   **纹理一致性限制**：由于没有硬掩码隔离，非编辑区域的纹理只能做到“接近”而非“像素级完全一致”，在某些极端精细的纹理保留上可能略逊于硬掩码方法。
*   **Backbone 依赖**：VS3D 的编辑质量上限受限于底层生成器（如 TRELLIS）的生成能力，生成器的固有缺陷会遗传到编辑结果中。
*   **应用限制**：目前主要针对孤立的 3D 物体，对于复杂场景或具有复杂遮挡关系的资产编辑效果尚待进一步验证。
