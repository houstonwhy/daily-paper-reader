## Abstract
View-conditioned 3D generators such as SAM 3D, TRELLIS and Hunyuan3D produce high-quality object reconstructions from a single view, but real-world visual observation often arrives as long monocular streams. Naively applying these generators to each streaming frame independently leads to severe temporal inconsistency in the generated results. To address this problem, we propose Stream3D, the first training-free streaming mechanism that turns a frozen view-conditioned 3D generator into a streaming generator with constant cross-chunk memory. Stream3D achieves this by maintaining a compact evidential memory, which selectively caches the most informative historical frames based on a proposed evidence score mechanism. As the stream progresses, the memory dynamically updates to retain a fixed number of informative frames, preventing the memory footprint from growing linearly with sequence length. This also prevents degradation over long sequences and keeps the underlying generator completely unchanged without retraining, architectural modifications, or auxiliary losses. Evaluated on both realistic and synthetic streaming benchmarks, Stream3D outperforms latent-transport baselines, including KV-cache reuse and flow-based feature editing, across both photometric and geometric metrics. *   **研究背景**：当前的 3D 生成模型（如 SAM 3D, TRELLIS 等）在单视图重建上表现优异，但在处理现实世界中的单目长视频流（如手机环绕拍摄、机器人移动观察）时面临挑战。
*   **核心问题**：
    1.  **不一致性**：逐帧独立应用单视图生成器会导致生成的 3D 结果在时间上严重不连贯。
    2.  **计算开销**：将所有帧作为多视图输入会导致计算量随序列长度线性增长。
    3.  **状态漂移**：现有的隐空间传输（Latent Transport）方法（如 KV-cache 复用或 FlowEdit）在长序列中容易产生误差累积，导致生成质量退化。
*   **研究动机**：开发一种**免训练（Training-free）**、**内存占用恒定**且能保持长程一致性的流式 3D 生成机制。

### 2. 方法论
Stream3D 的核心思想是将流式 3D 生成视为一个“证据选择”问题，而非“隐空间传输”问题。
*   **自适应证据记忆（Adaptive Evidential Memory）**：
    *   **证据得分（Evidence Score）**：利用冻结生成器内部的交叉注意力图（Cross-attention maps），计算每个查询标记（Query Token）对输入帧的关注程度和选择性。得分越高，表示该帧对该空间区域提供的几何/纹理信息越可靠。
    *   **记忆更新**：为每个查询标记维护一个固定容量（深度为 $D$）的列表，仅保留得分最高的历史帧索引。这种标记级别的记忆使得不同空间区域可以从不同的历史观察中提取证据。
    *   **恒定内存**：由于只存储索引和得分，内存占用不随序列长度增加（例如 SAM 3D 仅需约 65KB）。
*   **基于证据的多视图生成（Evidence-Based Multi-Generation）**：
    *   **视图选择**：通过标记“投票”机制，选出全局贡献最大的前 $K$ 个帧作为当前块的条件信号。
    *   **多扩散融合（Multi-Diffusion Fusion）**：在生成器的推理过程中，根据证据得分对不同视图生成的预测进行加权融合，确保生成的 3D 结构与历史观察一致。
*   **算法流程**：每个数据块（Chunk）先进行一次轻量级的预热（Warmup）以提取注意力图并更新记忆，随后进行正式的多视图融合生成。

### 6. 主要结论与发现
*   **性能领先**：Stream3D 在几何和外观指标上均显著优于单视图和现有的流式传输基准。
*   **非退化属性**：由于记忆机制只保留最高证据得分的帧，随着流的推进，生成质量会稳步提升或保持，而不会像隐空间传输方法那样随时间崩溃。
*   **细粒度优势**：标记级别的证据记忆比帧级别的视图选择更有效，因为它允许 3D 空间的不同部分参考最适合它们的历史视角。

### 7. 优点
*   **即插即用**：无需重新训练模型，不改变原始生成器的架构或权重。
*   **内存友好**：内存占用恒定，适合在资源受限的设备上处理无限长的视频流。
*   **可解释性**：通过证据得分可以直观地看到模型在生成特定区域时参考了哪些历史帧。
*   **鲁棒性**：有效解决了长序列中的误差累积和时间不一致问题。

### 8. 不足与局限
*   **基础模型依赖**：其性能上限受限于底层预训练生成器（如 SAM 3D）的质量。如果基础模型无法处理某些极端视角，Stream3D 也难以修复。
*   **计算开销**：虽然内存恒定，但每个块需要额外的预热步骤，这会增加一定的推理延迟。
*   **场景限制**：目前主要针对以物体为中心的（Object-centric）重建，对于大规模场景或动态背景的处理能力尚待验证。
