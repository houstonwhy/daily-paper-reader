## 摘要
最近基于生成式场景合成的 3D 世界建模系统（如 Marble）可以创建连贯且可探索的 3D 环境，但其输出通常是静态的整体资产，可编辑性和物理交互受限。这限制了它们在沉浸式内容创作和具身模拟中的应用，在这些场景中，生成的世界必须能够被主动修改和操纵。为了应对这一挑战，我们提出了 WorldAct，这是一个将静态生成的 3D 世界转换为可编辑且具备交互能力场景的框架。WorldAct 使用多模态智能体来引导场景分解，识别可操作物体，重建用于交互的几何对齐的物体级网格，并通过 3D 修复还原剩余背景。生成的场景支持物体级编辑、碰撞感知的操纵以及具身任务执行，同时保持了全局场景的连贯性。实验表明，WorldAct 能够实现比原始生成场景更丰富的交互场景，为通往可编辑和交互式 3D 世界模型提供了一条切实可行的路径。

## Abstract
Recent 3D world modeling systems based on generative scene synthesis, such as Marble, can create coherent and explorable 3D environments, yet their outputs are typically static monolithic assets with limited editability and physical interaction. This restricts their use in immersive content creation and embodied simulation, where generated worlds must be actively modified and manipulated. To tackle this challenge, we present WorldAct, a framework that converts static generated 3D worlds into editable and interaction-ready scenes. WorldAct uses a multimodal agent to guide scene decomposition, identify actionable objects, reconstruct geometrically aligned object-level meshes for interaction, and restore the residual background via 3D inpainting. The resulting scenes support object-level editing, collision-aware manipulation, and embodied task execution while preserving global scene coherence. Experiments show that WorldAct enables richer interaction scenarios than the original generated scenes, suggesting a practical path toward editable and interactive 3D world models.

### 2. 方法论：核心思想与技术细节
WorldAct 提出了一个由多模态智能体驱动的自动化流水线，主要包含以下四个阶段：

*   **场景分解（Scene Decomposition）**：
    *   **智能体驱动发现**：利用视觉语言模型（如 Qwen3.6-Plus）分析场景关键帧，自动识别可交互物体并生成文本提示。

*   **场景修复（Scene Restoration）**：
    *   **背景补全**：移除物体后，利用视频修复模型（DiffuEraser）和深度估计补全背景空洞，并重新优化背景高斯。
    *   **碰撞代理构建**：通过泊松重建和 RANSAC 平面检测，从背景中提取轻量化的水密网格（Mesh），为物理模拟提供碰撞边界。
*   **物体资产生成（Object Generation）**：
    *   **最优视角选择**：智能体评估所有观测视角，选择遮挡最少、特征最清晰的视角。
    *   **高质量重建**：利用 SAM3D 模型从单视角生成完整的、具备水密几何的 3D 资产，解决原始场景中物体背面缺失或模糊的问题。
*   **场景组装（Scene Assembly）**：
    *   **两阶段对齐**：先通过 ICP（迭代最近点）算法进行粗对齐，再通过可微渲染优化平移、旋转和缩放，确保生成的物体资产完美嵌入修复后的背景中，并符合物理支撑关系。

### 6. 主要结论与发现
*   **自动化能力**：WorldAct 能够无需人工标注地从整体场景中提取出绝大多数可交互物体。
*   **质量保持**：在引入交互性的同时，修复后的场景在感知质量（MANIQA）上甚至优于原始生成的模糊场景。

### 7. 优点（亮点）
*   **Agent-Loop 闭环**：巧妙地利用 VLM 解决了“哪些物体能动”和“哪个视角最好”的决策问题，实现了高度自动化。
*   **物理感知**：不仅修复了视觉，还构建了碰撞代理网格，使生成场景真正具备了“可模拟性”。
*   **解耦彻底**：实现了物体与背景的完全解耦，支持独立的几何、纹理和材质编辑。

### 8. 不足与局限
*   **依赖性强**：框架性能高度依赖于底层 3D 世界模型（如 Marble）和物体生成模型（如 SAM3D）的质量。
*   **动态性缺失**：目前仅处理静态物体的拆解，无法处理具有关节的物体（如能打开的抽屉）或流体。
*   **物理参数简化**：虽然有了碰撞几何，但尚未自动估算物体的质量、摩擦力、重心等关键物理属性。
*   **处理耗时**：每场景 1 小时的处理速度对于实时交互生成仍有较大距离。
