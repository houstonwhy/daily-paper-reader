## 摘要
最近 3D 生成建模的大多数进展都依赖于扩散或流匹配公式。与之不同，我们探索了一种完全自回归的替代方案，并引入了 GaussianGPT。这是一个基于 Transformer 的模型，通过下一标记预测直接生成 3D 高斯，从而实现了完整的 3D 场景生成。我们首先使用带有向量量化的稀疏 3D 卷积自编码器，将高斯基元压缩到离散的潜空间网格中。生成的标记被序列化，并使用带有 3D 旋转位置嵌入的因果 Transformer 进行建模，从而实现了空间结构和外观的顺序生成。与整体优化场景的基于扩散的方法不同，我们的方案逐步构建场景，自然地支持补全、外扩、通过温度进行的受控采样以及灵活的生成范围。这种方案利用了自回归建模的组合归纳偏置和可扩展性，同时在与现代神经渲染流水线兼容的显式表示上运行，将自回归 Transformer 定位为可控且上下文感知的 3D 生成的一种补充范式。

## Abstract
Most recent advances in 3D generative modeling rely on diffusion or flow-matching formulations. We instead explore a fully autoregressive alternative and introduce GaussianGPT, a transformer-based model that directly generates 3D Gaussians via next-token prediction, thus facilitating full 3D scene generation. We first compress Gaussian primitives into a discrete latent grid using a sparse 3D convolutional autoencoder with vector quantization. The resulting tokens are serialized and modeled using a causal transformer with 3D rotary positional embedding, enabling sequential generation of spatial structure and appearance. Unlike diffusion-based methods that refine scenes holistically, our formulation constructs scenes step-by-step, naturally supporting completion, outpainting, controllable sampling via temperature, and flexible generation horizons. This formulation leverages the compositional inductive biases and scalability of autoregressive modeling while operating on explicit representations compatible with modern neural rendering pipelines, positioning autoregressive transformers as a complementary paradigm for controllable and context-aware 3D generation.

### 2. 方法论：核心思想与关键技术
GaussianGPT 的工作流程分为两个阶段：**场景压缩（标记化）**和**自回归建模**。

*   **核心思想**：将连续的 3D 高斯基元压缩为离散的潜变量网格，然后将其序列化为 Token 流，利用 GPT 架构预测下一个 Token。
*   **关键技术细节**：
    1.  **稀疏 3D 潜编码（Compression）**：
        *   将 3D 高斯属性（位置、不透明度、缩放、旋转、颜色）投影到稀疏 3D 特征网格中。
        *   使用**稀疏 3D 卷积自编码器**进行下采样。
        *   采用**无查找量化（LFQ）**将特征映射为离散代码簿索引（Tokens）。
    2.  **3D 网格序列化（Serialization）**：
        *   采用简单的 **xyz 遍历顺序**将 3D 网格线性化。
        *   设计了**交替 Token 结构**：位置 Token ($p_i$) 和特征 Token ($f_i$) 交替出现，分别由不同的预测头处理。
    3.  **3D 旋转位置编码（3D RoPE）**：
        *   为了弥补 1D 序列化破坏的空间局部性，在 Transformer 的注意力机制中注入真实的 3D 坐标信息，使模型能感知空间邻近性而非仅序列邻近性。
    4.  **自回归 Transformer**：
        *   基于 GPT-2 架构，使用因果掩码进行训练。支持通过滑动窗口（Sliding Window）进行长程场景外扩。

### 6. 主要结论与发现
*   **AR 范式可行性**：自回归 Transformer 在 3D 高斯生成上是扩散模型的强力竞争者，尤其在物体生成指标（FID/KID/COV）上超越了现有 SOTA。
*   **3D RoPE 的关键性**：显式的空间位置编码对于处理序列化后的 3D 数据至关重要。
*   **灵活的补全能力**：同一个模型无需修改架构即可自然支持无条件生成、条件补全和无限外扩。
*   **xyz 顺序的优势**：尽管空间填充曲线（如 Hilbert）理论上局部性更好，但在 3D 生成任务中，简单的 xyz 遍历配合 3D RoPE 效果更佳且更易学习。

### 7. 优点
*   **增量生成能力**：支持步进式构建场景，非常适合交互式设计和大规模环境合成。
*   **统一框架**：将补全、外扩和生成统一在“下一标记预测”任务下，逻辑简洁。
*   **高质量表示**：结合了 3DGS 的渲染效率和离散潜空间的建模稳定性。
*   **可控性**：可以通过调节采样温度（Temperature）和 Nucleus Sampling 灵活控制生成结果的多样性。

### 8. 不足与局限
*   **自编码器瓶颈**：在处理真实世界数据（ScanNet++）时，自编码器的保真度限制了高频细节的恢复，导致几何结构略显嘈杂。
*   **空洞问题**：由于场景稀疏，自回归预测有时会产生空列（无占据），需要通过“重采样（Resampling）”策略来缓解。
*   **推理速度**：相比于单次前向传播的非自回归模型，逐 Token 生成在大规模场景下耗时较长（受限于序列长度）。
*   **累积误差**：长程外扩时可能存在潜在的漂移或一致性减弱风险（虽然文中展示了 12m 场景，但更长距离的稳定性待验证）。
